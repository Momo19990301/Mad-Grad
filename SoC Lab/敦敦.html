Trivia

「小忠狗 ฅ´ᴥ`ฅ 」敦敦堪稱「犬系男友」的活招牌，忠誠、黏人、愛撒嬌，完美詮釋什麼叫「你一動，我就跟」。他那份維妙維肖的貼心演出，讓人一試成主顧、再試上癮。
直到有一天大家發現，這一切的源頭 — 原來是他對「球球」有著異於常人的執著與熱愛。某種程度上，他不只是忠誠，是會為你撿球撿到世界盡頭。

「帶妳吃薯條 ( ♥д♥)」別人說「我請妳吃大餐」，敦敦說：「我帶妳吃薯條」
聽起來平平無奇，但這招出奇致勝 — 速食店裡的美味魔法搭配敦敦的暖男攻勢，竟然能一發入魂，幾乎百發百中。

「手把手寫 code つ◕_◕つ」作為 Lab 的資深把關人，敦敦不僅耐心教導學弟 coding，還在 coding bar 擔任講師，認真作育英才。然而他的仁慈竟然導致不久的未來一連串的危機與厄運！？

「還我行李 ಥ_ಥ」就算是強如敦敦，也難逃命運的毒打 — 他的行李總是莫名其妙被搞丟，據說是因為裡頭藏了炸彈吧～💣💼
